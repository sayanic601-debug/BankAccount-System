## Bank Account Management System

A simple interactive Bank Account Management System developed using Java.

## Features

- Deposit money into the account.
- Withdraw money from the account.
- Check current account balance.
- Handle insufficient balance using exception handling.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Scanner
- Exception Handling

## How to Run

javac BankAccount.java

java BankAccount
